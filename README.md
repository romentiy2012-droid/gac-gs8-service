# GAC GS8 — сервисный журнал (PWA)

Готовое мобильное веб-приложение для публикации через GitHub Pages. Регистрация посетителям не нужна. Данные автомобиля и история ТО хранятся локально на устройстве; в разделе «История» можно скачать резервную копию JSON и восстановить её после очистки браузера или на другом устройстве.

## Как опубликовать на GitHub

1. Распакуйте ZIP-архив на компьютере.
2. На GitHub нажмите **New repository** и создайте новый **Public**-репозиторий, например `gac-gs8-service`.
3. В открывшемся пустом репозитории нажмите **uploading an existing file**.
4. Перетащите в окно **всё содержимое распакованной папки**, включая папки `.github`, `public` и `src`. Файлы должны лежать в корне репозитория, а не во вложенной общей папке.
5. Внизу страницы нажмите **Commit changes**.
6. Откройте **Settings → Pages** и в пункте **Source** выберите **GitHub Actions**, если этот вариант ещё не выбран.
7. Откройте вкладку **Actions** и дождитесь зелёной галочки у процесса «Публикация GAC GS8 PWA».

Рабочий адрес будет таким:

`https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

Например, для логина `ivan` и репозитория `gac-gs8-service`:

`https://ivan.github.io/gac-gs8-service/`

## Установка на телефон

- **Android / Chrome:** откройте ссылку → меню браузера → «Установить приложение» или «Добавить на главный экран».
- **iPhone / Safari:** откройте ссылку → кнопка «Поделиться» → «На экран “Домой”».

После первого успешного открытия приложение сможет запускаться без интернета. Чтобы не потерять историю при удалении браузера или очистке его данных, периодически открывайте **История → Скачать копию** и сохраняйте JSON-файл в iCloud, Google Drive или другое надёжное место.

Если данные уже внесены в предыдущую версию приложения, сначала скачайте там резервную копию, затем на новом адресе GitHub Pages откройте **История → Восстановить** и выберите сохранённый JSON-файл.

## Локальный запуск для разработчика

```bash
npm install
npm run dev
```

Проверка итоговой сборки:

```bash
npm run build
```
